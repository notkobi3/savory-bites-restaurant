# Savory Bites Restaurant Website

A **professional** restaurant website created with HTML, CSS, and JavaScript featuring advanced interactive components.

## Project Structure

- `index.html` - Main HTML file
- `styles.css` - CSS styling
- `script.js` - JavaScript functionality
- `README.md` - Project documentation

## Features

- Responsive navigation
- Smooth scrolling
- Modern CSS styling
- Interactive JavaScript features

## Getting Started

1. Open `index.html` in your web browser
2. Or use a local development server like Live Server in VS Code

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
